# Clearbill

A lightweight accounts-receivable tracker for small businesses. Add invoices, see outstanding, overdue, and upcoming balances at a glance, and mark payments as received. Your invoice data is saved locally in your browser.

## Run

Open `index.html` in a modern browser. No installation or server is required.

Amounts are tracked in USD. Data stays in the browser where it was entered and is not sent to a server.
